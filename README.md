# Panah

An OpenVPN control plane: a web panel that provisions and manages OpenVPN
inbounds across a fleet of nodes, issues client certificates, exposes per-client
subscriptions, and accounts for traffic — with a small agent that runs on each
node.

## Layout

| Path | What it is |
| --- | --- |
| `panel/` | Python application: FastAPI API, SQLAlchemy models, service layer and the node agent |
| `panel/api/routes/` | HTTP surface (`/api/auth`, `/api/nodes`, `/api/inbounds`, `/api/clients`, `/api/tunnels`, `/api/system`, `/sub/...`) |
| `panel/services/` | Side effects: PKI, OpenVPN config rendering, tunnels, nginx/certbot, traffic accounting, planning, scheduler |
| `panel/core/` | Cross-cutting pieces: security, crypto, audit, logging, rate limiting |
| `web/` | React + TypeScript + Vite single-page UI |
| `tests/` | Pytest suite (unit + API level) |
| `install.sh`, `uninstall.sh` | Production installer for a Debian/Ubuntu host |

## Requirements

- Python 3.11+
- Node 20+ (only for the web UI)

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt

# create the schema, an administrator and a local node, then run the panel
.venv/bin/panah bootstrap
.venv/bin/panah serve            # http://127.0.0.1:8080
```

The web UI runs against the panel with Vite's dev server:

```bash
cd web
npm install
npm run dev        # proxies /api to the panel
```

Runtime settings are read from the environment. `.env.example` documents every
variable; copy it to `.env` for local work. Secrets are generated by the
installer and live in `/etc/panah/secrets/` in production.

Other CLI verbs: `panah agent`, `panah create-user`, `panah reset-password`,
`panah enable-totp`, `panah doctor`, `panah version`.

## Tests and lint

```bash
.venv/bin/pytest          # full suite
.venv/bin/pytest tests/test_openvpn.py -k route
.venv/bin/ruff check panel tests    # the enforced lint gate
```

`pyproject.toml` holds the pytest and ruff configuration, so both tools pick up
the project settings with no extra flags.

`ruff check` is the gate that must stay clean. `ruff format` is available but is
not enforced: the renderers use deliberate wrapping that the formatter would
rewrite, so running it produces a large unrelated diff. Format only the files
you are already touching.

## Frontend checks

```bash
cd web
npm run typecheck
npm run build     # emits web/dist, served by the panel in production
```

## Deployment

`install.sh` provisions the host, installs the panel and the agent from a
checkout, and can front the panel with nginx and Let's Encrypt certificates.
Run `panah doctor` after installing to verify the host state.
